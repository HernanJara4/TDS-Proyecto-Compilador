// Test OPT 01: Plegado de constantes (Constant Folding), propagacion de
// constantes y simplificacion algebraica (x + 0, x * 1, x - x).
// Toda la expresion constante (2 + 3) * 4 + (10 / 2) se pliega a 25 en
// compilacion, y las identidades algebraicas se simplifican.
// Resultado esperado al ejecutar el binario (exit code): 25 + 7 = 32.

int main() {
    int a, b, c;
    a = (2 + 3) * 4 + (10 / 2); // Se pliega completo a: a = 25
    b = 7;
    c = (b * 1) + 0 + (b - b);  // Se simplifica a: c = b
    return a + c;
}
